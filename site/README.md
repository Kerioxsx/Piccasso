# Piccasso website

`index.html` is a self-contained page (Google Fonts only) in a black-and-white sketch-paper style: the hero sketch draws itself with a pencil, doodles redraw on scroll, and product videos sit in hand-drawn frames. `media/` holds real recordings of the app, regenerated with `node tools/record-videos.mjs` (web app) plus the desktop captures. Serve the folder with any static server.
